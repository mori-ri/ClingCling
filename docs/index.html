ClingCling
English GitHub ダウンロード

ClingCling はコピーした内容を Mac の中で見分けて、次の操作を提案するクリップボードです。⌘⇧V でカーソルの横に履歴を開き、そのままキーボードで選べます。

ダウンロード

macOS 14 以降。GitHub の Releases ページが開きます。

見出しの行を押すと、提案が切り替わります。

コピーしたものごとに、提案が変わる

左にあるほどおすすめの操作です。使うほど、よく選ぶ操作が前に来ます。学習も統計も Mac の中だけで行います。

ここで試せます。見本を押して ⌘C、続けて ⌘⇧V を押すと、その場でポップアップが開きます。このページのどの文章でも同じです。判定はブラウザの中で動き、コピーした文字はどこにも送りません。

履歴は入力するだけで絞り込める

大文字と小文字、全角と半角、ひらがなとカタカナの違いは無視します。空白で区切ると AND 検索です。日本語の変換中は、確定や移動のキーを入力の邪魔にならないよう IME に渡します。

カーソルの位置が取れないアプリでは、マウスの位置に開きます。ショートカットは設定で変更できます。

ClingCling は通信しません

判定はすべて Mac の中で行います。コピーしたものは、種類によって届く範囲を変えています。ほとんどの内容は Mac の外に出ることがありません。

コピーしたものメモリディスクAI
受け取らないパスワードマネージャー、機密の印が付いたコピー、除外したアプリ なしなしなし
5 分で消えるAPI キー、JWT、秘密鍵、カード番号、認証コード 5 分だけ書かない渡せない
Mac の中だけメール、電話番号、住所、画像、ランダムな文字列 保持保存する渡せない
頼んだときだけ AI へ文章、URL、コード、コマンド、エラー、JSON 保持保存する確認のあと

見つけられないもの

  • 判定は規則とエントロピーによるものです。形式に当てはまらないパスワードや氏名は検出できず、ふつうの文章として保存され、AI にも渡せます。渡す前の確認画面で内容を確かめてください。
  • コピー元のアプリは、0.4 秒ごとの確認で最前面にあるアプリとして判定します。コピーの直後にアプリを切り替えると、別のアプリと判定されることがあります。

保存のしかた

  • 履歴は SQLite に保存し、ファイルの権限は 0600 です。暗号化はしていません。
  • 保存先は Time Machine のバックアップから除外します。
  • Web ページ以外のリンクと Terminal での実行は、動かす前に確認します。

AI には、頼んだときだけ渡します

API キーは要りません。いつも使っている Claude や ChatGPT のアプリか Web に、指示文を付けて本文を渡します。設定で有効にするまで、この機能は動きません。

  1. 履歴で → を押して「説明する」を選びます
  2. 確認画面で、渡す指示と本文を読みます
  3. アプリを開いて新しいチャットに貼り付けます。URL で渡すこともできます
  4. 終わったら、クリップボードを元の内容に戻します

指示文は書き換えられます。「3 行で要約」「敬語に直す」のように、自分の操作を名前を付けて増やすこともできます。

Mac に入れる

zip を展開して、ClingCling.app をアプリケーションフォルダに移動して開きます。カーソルの横に開くには、アクセシビリティの権限が必要です。

ダウンロード

macOS 14 以降。Developer ID で署名し、Apple の公証を受けています。

ソースからもビルドできます。Xcode は要りません。

git clone https://github.com/mori-ri/ClingCling.git
cd ClingCling
./scripts/bundle.sh
open build/ClingCling.app
