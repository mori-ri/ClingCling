# /brag — ClingCling

## 何か（一文）
コピーした内容を Mac の中で見分けて、次の操作を先回りして提案するメニューバーのクリップボード。

- **誰のため**: コピーのあとに毎回「ブラウザへ切り替えて貼る」「AI を開いて指示を書く」をしている Mac ユーザー。
- **違い**: 種類ごとに次の一手が変わる（URL は開く、エラーは AI に聞く、API キーは残さない）。判定はすべてローカル。
- **一番強い主張**: API キーはディスクに書かず、5 分で消える。聞かずに通信しない。
- **ビジュアルのフック**: LP のヒーローそのもの — 選択したように反転する 3 行の見出しと、カーソルの横に開くポップアップ。
- **見せる UI**: LP の `site.js` にある実物のポップアップ再現（`ContentClassifier` / `SecretDetector` / `ActionRanker` を移した判定がそのまま動く）。
- **トーン**: default（軽快・クリーン）。
- **シェア文**: 「URL は開く。エラーは AI に聞く。API キーは残さない。」

## ビジュアル
- 色はロゴ由来のみ: コーラル `#FF6B84`、強調 `#D92E54`、ネイビー `#001A42`、シアン `#00D8FE` は一点だけ光らせる。
- 見出し: Dela Gothic One（LP のサブセット。LP にある文字だけを使う）。本文: Inter + Noto Sans JP。
- ポップアップは LP の CSS と描画関数を流用し、2 倍に拡大して見せる。
- 文言はすべて LP / README の既存コピー。API キーは LP と同じ形だけの見本（`sk-ant-api03-SAMPLEonly…`）で、画面では伏せて表示される。

## 音
120 BPM（1 拍 0.5 秒）、ニ長調。キック・ハット・クラップ、ベース、エレピ風のコード、プラックのメロディ。
効果音（キーのクリック、ポップアップのポン、カットのスウッシュ）は同じ調・同じ拍に置き、音楽の下に小さく混ぜる。
